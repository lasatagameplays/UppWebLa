# Política de Seguridad

## Versiones Soportadas
Actualmente, las siguientes versiones de **UppWebLa** reciben actualizaciones de seguridad:

| Versión | Soportada |
| ------- | ------------------ |
| 3.1.x   | :white_check_mark: |
| < 3.0   | :x:                |

## Reportar una Vulnerabilidad
La seguridad de este proyecto es una prioridad absoluta.

Si descubres una vulnerabilidad de seguridad en **UppWebLa**, por favor **NO** abras un Issue público. En su lugar, envía un correo electrónico detallado a soporte a través del dominio principal [LASATA.EU](https://lasata.eu). 

Todas las vulnerabilidades de seguridad serán evaluadas y parcheadas lo antes posible. Agradecemos tu ayuda para proteger este ecosistema.

# Security Policy

## Supported Versions
Currently, the following versions of **UppWebLa** receive security updates:

| Version | Supported |

| ------- | ------------------ |

| 3.1.x | :white_check_mark: |

| < 3.0 | :x: |

## Reporting a Vulnerability
The security of this project is a top priority.

If you discover a security vulnerability in **UppWebLa**, please **DO NOT** open a public issue. Instead, send a detailed email to support via the main domain [LASATA.EU](https://lasata.eu).

All security vulnerabilities will be evaluated and patched as soon as possible. We appreciate your help in protecting this ecosystem.
